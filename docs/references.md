# References

## AI-Based Signal Analysis, Demodulation & Intelligence Platform

This document contains the main technical references identified for the SignalAI SIH 2026 concept.

The references cover signal processing, software-defined radio, machine learning, modulation classification, demodulation, decoding, and related research areas.

---

## 1. GNU Radio

**GNU Radio** is an open-source software development toolkit used for signal processing and software-defined radio applications.

### Relevance to SignalAI

GNU Radio is relevant to areas such as:

* Signal processing
* Software-defined radio
* Modulation and demodulation
* Signal flowgraph design
* Real-time signal processing

### Reference

GNU Radio — Official Documentation

https://www.gnuradio.org/

---

## 2. PySDR

**PySDR** provides educational material covering software-defined radio and digital signal processing concepts.

### Relevance to SignalAI

Relevant areas include:

* IQ signals
* Sampling
* Fourier transforms
* Digital modulation
* Demodulation
* Software-defined radio

### Reference

PySDR — A Guide to SDR and DSP using Python

https://pysdr.org/
